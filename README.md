# Laravel Shopping Cart

An updated, maintained fork of `darryldecode/laravelshoppingcart` supporting **Laravel 10, 11, 12, and 13** on **PHP 8.2+**.

It is a direct drop-in replacement that preserves existing classes, facades, and configuration keys.

---

## Installation

Install the package via Composer:

```bash
composer require alexpechkarev/laravelshoppingcart
